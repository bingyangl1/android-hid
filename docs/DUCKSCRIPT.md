# DuckyScript 语法参考（规划中）

## 说明

DuckyScript 是 USB Rubber Ducky 标准脚本语言。本项目的 DuckyScript 引擎尚在规划中。

## 示例

```duckyscript
DELAY 1000
GUI r
DELAY 500
STRING notepad
ENTER
DELAY 500
STRING Hello World from DuckyScript!
```

## 计划支持的命令

| 命令 | 说明 |
|------|------|
| STRING | 输入文本 |
| DELAY | 延时 (ms) |
| GUI/WINDOWS | Win 键 |
| CTRL/SHIFT/ALT | 修饰键 |
| ENTER/ESC/TAB | 特殊键 |
| F1-F12 | 功能键 |
| UP/DOWN/LEFT/RIGHT | 方向键 |
